## Outcome

R001 freezes the current Python runtime lifecycle as a deterministic migration
oracle. The committed fixture is generated by
`tests/migration_rs/runtime_lifecycle_fixtures.py` from the production runtime,
reload, task, policy, and application boundaries named by the plan. It records
ownership, candidate/slot/swap/transaction states, lease and publication-gate
rules, reload result categories, task schedules and enablement conditions,
active-generation authority, retirement, and process shutdown semantics.

The oracle is evidence-only. It adds no Rust runtime manager, dependency,
server behavior, database migration, background loop, control socket, CLI
surface, or production Python behavior.

## Fixture contents

- `migration-rs/fixtures/runtime-lifecycle/r001-python-observations.json`

- `eggpool.runtime_manager`
- `eggpool.generation_factory`
- `eggpool.config_reload_policy`
- `eggpool.reload_transaction`
- `eggpool.runtime_task_inventory`
- `eggpool.runtime_tasks`
- `eggpool.reload_diagnostics`
- `eggpool.app`
- `eggpool.cli_rehash_helper`

The candidate abort probe uses only local callbacks. It verifies that
candidate resources close in reverse registration order and that process-owned
resources are untouched.
