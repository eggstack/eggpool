# Rust Migration Closure Records

A milestone is not complete merely because code landed.

Closure records live at `closure/<subsystem>/NNN-status.md` and must contain implementation commit/PR references, requirement-to-evidence matrix, differential results, commands actually run, migration/database/config/API/SSR evidence as applicable, security/contention/restart evidence, known limitations, unresolved findings by severity, and one recommendation: closed, conditionally closed, corrective pass required, or blocked.

Do not claim commands that were not run. A supported difference requires an accepted ADR or explicit canonical decision, not a closure-record waiver.
