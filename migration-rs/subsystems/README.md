# Rust Migration Subsystem Roadmaps

Subsystem roadmaps translate the canonical migration specification into coherent workstreams. They are longer-lived than implementation plans and shorter-lived than the canonical roadmap.

A subsystem roadmap must define ownership boundary, relevant invariants, current Python evidence, dependencies, ordered milestones, non-goals, risks, and user-visible exit conditions.

Only dependency-ready milestones receive detailed handoff plans under `../implementation/`.
