# Migration history

EggPool's Python-to-Rust migration completed with the 0.8.0 native release
and the final M12/P007 closure. Git history is the archive for the retired
scaffold; the historical Python source and migration evidence can be recovered
from commit `c6b5d2c25038a8ac155c71f68fd50afea03fa459` (tree
`2887b6b6a3be38ad8b386781cda76f888d5ac0dc`).

Current exact-version compatibility and rollback policy are maintained in
[releasing](releasing.md) and [upgrading](upgrading.md).
