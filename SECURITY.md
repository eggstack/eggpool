# Security Policy

## Reporting a vulnerability

Please report suspected EggPool vulnerabilities privately rather than posting
exploit details, credentials, or sensitive reproduction steps in a public issue.
The preferred channel is GitHub's private vulnerability reporting for this
repository:

<https://github.com/eggstack/eggpool/security/advisories/new>

If private reporting is unavailable, do not publish exploit details in an
issue. Use a public issue only to ask maintainers for a private reporting
channel, without including sensitive technical details.

Reports should identify the affected EggPool version and platform, describe the
impact and a minimal reproduction, and distinguish confirmed behavior from
speculation. Do not include live credentials, private user data, prompts, or
provider request/response bodies.

Maintainers should enable GitHub private vulnerability reporting for this
repository so researchers have a private channel available.

## Supported versions

Report security issues against the current release. Older versions may not
receive security fixes; include the version you tested so maintainers can assess
whether the issue affects a supported release.
